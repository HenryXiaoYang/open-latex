\section{Constructs outside the allow-list}
P01 Inline TikZ: a diagram \tikz[baseline]{\draw[blue] (0,0) -- (1ex,1ex) circle (1pt);} inside a sentence, followed by enough words for the paragraph to wrap onto a second line of text.

P02 Boxes from graphicx: \scalebox{1.5}{bigger} and \rotatebox{10}{tilted} and \resizebox{3cm}{!}{resized text} inside running text that continues for a while so that it wraps.

P03 Case changes: \MakeUppercase{shouting} and \MakeLowercase{QUIET} and \uppercase{primitive} in a paragraph of ordinary text that wraps onto the next line.

P04 Primitives: a \kern2pt kern, a \hskip 5pt plus 1pt hskip, \llap{x}overlap, \rlap{y}, \smash{smashed}, \hbox{boxed}, \lower2pt\hbox{lowered}, \raise2pt\hbox{raised} and \penalty0 a penalty.

P07 Page-dependent: this is page \thepage{} of the document, and the counter value is \arabic{page}, in a paragraph long enough to wrap onto another line of text.

P08 A margin note\marginpar{\small in the margin} inside a paragraph of running text that continues long enough to wrap onto a second line.

P09 A definition inside the paragraph: \newcommand{\local}{locally defined} then \local{} used right away, and \def\pl{plain def} \pl{} as well, in running text.

P10 \pagecolor{yellow!10}A global page colour set inside a paragraph (a state leak if it survives), with text after it.

P11 Hyperref targets: \hypertarget{tgt}{a target} and \hyperlink{tgt}{a link to it} and \href{https://example.org}{a URL} in a paragraph that wraps onto the next line of text.

P12 Math outside the list: $\boxed{E = mc^2}$, $\pmb{v}$, $\mathit{word}$, $\smash{\sqrt{x}}$, $\overset{a}{b}$, $\underset{c}{d}$, $\xrightarrow{f}$, $\mathring{a}$, $\breve{a}$, $\check{a}$, $\acute{a}$, $\grave{a}$.
